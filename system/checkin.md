# /api/system/checkin

The check-in handshake verifies device firmware and sets the RTC clock using trusted data from the Encedo cloud backend. This is a three-step process: device generates challenge -> cloud verifies -> device processes response.

---

## GET /api/system/checkin

Get the check-in challenge from the device.

### Request

```
GET /api/system/checkin
```

**Authentication:** Not required

### Response

**Status:** `200 OK`

```json
{
  "check": "check_in_challenge_data"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `check` | String | Check-in challenge data generated by HEM |

---

## POST /api/system/checkin

Submit the cloud-verified check-in response back to the device.

### Request

```
POST /api/system/checkin
Content-Type: application/json
```

```json
{
  "checked": "verified_checkin_data_from_backend"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `checked` | String | Yes | Check-in data verified and returned by `api.encedo.com/checkin` |

### Response

**Status:** `200 OK`

```json
{
  "newcrt": "tls_certificate_update_status",
  "newfws": "new_firmware_version_info",
  "newuis": "new_manager_version_info",
  "status": "general_checkin_status"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `newcrt` | String | TLS certificate update status |
| `newfws` | String | Available firmware update info (used to trigger update flow) |
| `newuis` | String | Available Manager UI update info (used to trigger update flow) |
| `status` | String | General check-in status |

### Error Codes

| Code | Description |
|------|-------------|
| 400 | Incorrect argument(s) |
| 401 | Provided data validation failed |

## Complete Check-in Flow

```javascript
// encedo.js:263-291, build.js:306-310
// Step 1: GET challenge from device
self.api('api/system/checkin')
// Step 2: POST challenge to cloud
.then(data => self.api('https://api.encedo.com/checkin', 'POST', data))
// Step 3: POST cloud response back to device
.then(data => self.api('api/system/checkin', 'POST', data))
.then(function(data) {
    if (data.newfws) self.encedo_update_firmware = data.newfws;
    if (data.newuis) self.encedo_update_dashboard = data.newuis;
});
```
